# Project Rules & Invariants

This project adheres to the global workspace rules:
- Anti-AI-slop design: No emojis, no pulsing neon dots, no nested border soup, no screaming uppercase badges.
- Vector icons only (flaticons / Lucide React SVG components).
- Mobile ergonomics: Minimum 44px touch targets, single scroll flow, safe-area clearance.
- Continuous verification: Always run `npm run lint` (0 errors, 0 warnings), `npm test` (all tests passing), and `npm run build` before completing work.
